# Plantillas con variables

Las variables también funcionan en Notas, el panel que abres con Comando J. Una nota con variables es una plantilla. Esta revisa un puerto con cuatro consultas que usan la misma variable.

Selecciona las líneas y presiona Comando Enter; en Windows y Linux, Control Enter. Se abre Completar plantilla: escribes cada valor una vez y ves la vista previa. La app recuerda los valores, salvo los que parecen secretos, como password, key o community: esos se piden ocultos y nunca se guardan.

Para enviar a varias sesiones, cambia el destino: pestañas elegidas, una carpeta o los paneles visibles. Las variables se piden una vez y el mismo valor va a todos los equipos.

Antes de enviar ves los equipos, los que se omiten y el riesgo. Si algo no es consulta, debes escribir la cantidad de equipos para confirmar. El envío va de un equipo a otro, con una pausa ajustable, y lo puedes detener.
