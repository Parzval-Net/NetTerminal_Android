# Plugins

Un plugin empaqueta acciones para compartirlas: una carpeta con un manifiesto, plugin.json, y código Python con la misma API. Sus acciones aparecen como botones en Herramientas, Plugins.

Este ejemplo, Revisión de puertos, tiene tres acciones: resumen por estado, puertos con errores y exportación a CSV. El manifiesto declara id, versión, archivo de entrada, acciones y permisos. main.py lee la acción elegida en la variable NT_ACTION, y la lectura de las tablas va en un segundo archivo.

Pide dos permisos. session es el que la app hace cumplir: sin él, el plugin no lee ni envía nada a la sesión. files, igual que network, es una declaración: Python corre con tus privilegios, así que te protege revisar el código.

Para instalarlo, elige Desde carpeta o Instalar .zip. La app rechaza manifiestos inválidos, enlaces simbólicos, más de 200 archivos o 20 megabytes, y código que no se puede leer, como bytecode o binarios.

Luego viene la revisión: permisos y todo el código Python, desde el archivo de entrada. Solo al presionar Instalar y habilitar queda activo, con una huella SHA-256 de sus archivos.

Para actualizarlo, sube la versión e instálalo de nuevo: la revisión avisa que reemplaza la instalada. Si alguien edita sus archivos directamente, se bloquea hasta que revises y apruebes el cambio. Con la papelera lo desinstalas.
