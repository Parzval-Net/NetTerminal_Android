# Servidores TFTP y HTTP

El Servidor TFTP usa el puerto 69. Pulsa Iniciar.

Debajo están los comandos para el equipo, listos para copiar: copy tftp para Cisco y tftp get para Huawei. Usan el primer archivo de la carpeta y la primera IP de la lista. Revisa ambos antes de pegar.

Por defecto TFTP solo entrega archivos. Para recibir, activa Permitir subidas. Se aplica al iniciar: si ya está activo, detenlo e inícialo de nuevo.

El Servidor HTTP usa el puerto 8080 y es solo de lectura. Su comando es copy http, con la IP y el puerto.

En Linux, los puertos bajo 1024 requieren privilegios. Si TFTP no inicia en el 69, usa el 1069, si el equipo permite indicar el puerto.

El flujo típico para un firmware. Uno: agrega la imagen con Agregar. Dos: revisa el espacio libre en el equipo. Tres: inicia HTTP, o TFTP si el equipo no soporta HTTP. Cuatro: pega el comando en la sesión. Cinco: sigue el avance en Transferencias. Seis: verifica el MD5 contra el del fabricante. Siete: detén el servidor.

El cambio de imagen y el reinicio quedan a tu cargo.
